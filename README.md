# AI Dictionary

An AI-powered dictionary web application built using Flask. Users can search for words, get AI-generated meanings and explanations, create accounts, and save learned words for future reference.

# Features

- User registration and login
- Search and learn word meanings
- AI-generated explanations
- Save learned words
- Responsive web interface
- Database integration using SQLAlchemy
- REST API endpoints for word lookup

# Tech Stack

- Python
- Flask
- Flask-SQLAlchemy
- Flask-WTF
- HTML
- CSS
- JavaScript
- SQLite

# Installation

1. Clone the repository

git clone https://github.com/Chitresh-nim/AiDictionary.git

2. Navigate to the project directory

cd AiDictionary

3. Create a virtual environment

python -m venv env

4. Activate the virtual environment

Windows:

env\Scripts\activate

5. Install dependencies

pip install -r requirements.txt

6. Run the application

python app.py
